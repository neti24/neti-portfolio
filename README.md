# Neti Sharma Portfolio

Animated React portfolio with responsive layout, dark/light mode, Framer Motion scroll reveals, hover interactions and mobile navigation.

## Run locally
```bash
npm install
npm run dev
```

## Customize
Replace placeholder email and social links in `src/main.jsx`. Add your resume to `public/resume.pdf` and connect the Resume button if needed.

## Deploy
Push to GitHub, then import the repository into Vercel or Netlify. Build command: `npm run build`; output directory: `dist`.
